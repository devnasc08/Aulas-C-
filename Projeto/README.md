# Flow Academy - Projeto Integrado

Este repositorio contem o projeto Flow Academy completo, com modulo web em PHP, modulo desktop em C# e banco de dados MySQL compartilhado.

## Onde comecar

Documentacao geral:

```text
docs/README.md
```

Documentacao PHP:

```text
FlowAcademy_php/docs/README.md
```

Documentacao CSharp:

```text
FlowAcademy_cs/docs/README.md
```

## Estrutura

```text
Projeto/
+-- FlowAcademy_php/
+-- FlowAcademy_cs/
+-- docs/
+-- procedures_para_Atual_conforme_CSharp.sql
```

## Modulos

### PHP Web

Aplicacao web em PHP puro, com paginas por perfil, Bootstrap local, PDO e controle de sessao.

Entrada principal:

```text
FlowAcademy_php/web-php/login.php
```

### CSharp Desktop

Aplicacao Windows Forms em .NET 8, com dashboard, formularios e biblioteca de classes.

Solucao:

```text
FlowAcademy_cs/FlowAcademy.sln
```

### Banco

Banco MySQL/MariaDB compartilhado pelos dois modulos.

Script oficial:

```text
FlowAcademy_php/banco/Banco_oficial.sql
```

Script auxiliar C#:

```text
procedures_para_Atual_conforme_CSharp.sql
```
