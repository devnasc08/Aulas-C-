# 13 - Glossario

## Admin

Perfil com maior nivel de acesso no sistema. Pode acessar painel administrativo, logs e cadastros de usuarios administrativos.

## Administrativo

Perfil responsavel por rotinas operacionais, como alunos, matriculas e pagamentos.

## Aluno

Usuario que consulta suas informacoes academicas, como boletim e frequencia.

## Alerta de risco

Registro usado para indicar risco academico por nota, frequencia ou ambos.

## Autenticacao

Processo de confirmar se e-mail e senha pertencem a um usuario valido.

## Autorizacao

Processo de verificar se o usuario logado tem permissao para acessar determinada pagina.

## Bootstrap

Biblioteca de CSS e JavaScript usada como base visual e interativa do sistema PHP. No projeto, a versao local usada e a 5.0.2, armazenada em `assets/bootstrap`.

## Coordenacao

Perfil responsavel por cursos, unidades curriculares, turmas e acompanhamento academico.

## Curso

Formacao oferecida pela escola, como um curso tecnico.

## Dashboard

Tela inicial de um perfil, com indicadores e atalhos principais.

## Disciplina

No projeto, representa uma unidade curricular vinculada a um curso.

## Frequencia

Controle de aulas e presencas do aluno em uma unidade curricular.

## Helper

Funcao auxiliar usada em varias partes do sistema.

## Log

Registro de uma acao executada por usuario, como login, logout ou cadastro.

## Matricula

Vinculo entre aluno e turma.

## Model

Classe que representa uma entidade do sistema, como Aluno, Usuario ou Curso.

## Nota

Registro de avaliacao do aluno em uma unidade curricular.

## PDO

Biblioteca do PHP usada para conexao e execucao de comandos no banco de dados.

## Perfil

Tipo de usuario usado para controlar acesso. Exemplos: aluno, professor, coordenacao, administrativo e admin.

## Professor

Perfil responsavel por turmas, lancamento de notas e registro de frequencia.

## Service

Classe que agrupa regras ou fluxos de uma area do sistema.

## Sessao

Recurso do PHP usado para manter o usuario logado durante a navegacao.

## SHA256

Algoritmo usado no projeto para gerar hash da senha, mantendo compatibilidade com o sistema desktop/C#.

## Turma

Oferta de um curso em um periodo letivo, vinculada a professor, turno e capacidade maxima.

## Unidade curricular

Parte do curso cadastrada na tabela `disciplinas`.
