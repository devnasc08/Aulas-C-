# Visao Desktop

## Papel do Desktop

O Desktop e o modulo administrativo do Flow Academy.

Ele deve permitir gestao de usuarios, alunos, professores, cursos, disciplinas, turmas, matriculas, notas, frequencias e pagamentos.

## Estrutura

- Projeto de Forms: `FlowAcademy`
- Projeto de classes: `FlowAcademyClasses`

## Pontos de atencao

- Garantir que nenhum form acesse banco diretamente.
- Padronizar classes.
- Corrigir procedures chamadas.
- Finalizar dashboard por perfil.
- Compilar apos cada etapa de correcao.

## Prioridade

Alta. O Desktop e a prioridade principal da estabilizacao.
