# Plano de Apresentacao

## Objetivo

Apresentar o Flow Academy como sistema de gestao escolar com modulo Desktop administrativo, modulo Web por perfil e banco MySQL compartilhado.

## Partes da apresentacao

| Parte | Responsavel |
|---|---|
| Introducao do projeto | A definir pelo grupo |
| Arquitetura geral | A definir pelo grupo |
| Banco de dados | A definir pelo grupo |
| Modulo Desktop | A definir pelo grupo |
| Modulo Web | A definir pelo grupo |
| Homologacao e bugs | A definir pelo grupo |
| Encerramento | A definir pelo grupo |

## Telas a demonstrar

### Desktop

- Login
- Dashboard `FrmPrincipal`
- Usuarios
- Alunos
- Professores
- Cursos
- Disciplinas
- Turmas
- Matriculas
- Notas
- Frequencias
- Pagamentos

Observacao: `FrmAlertaRisco` nao existe no Desktop e deve ser citado como pendencia documentada, se a banca perguntar.

### Web

- Landing Page
- Login
- Dashboard de aluno
- Dashboard de professor
- Dashboard de coordenacao
- Dashboard administrativo
- Area de pagamentos, se validada

## Fluxo sugerido

1. Explicar o problema que o sistema resolve.
2. Mostrar arquitetura Desktop, PHP e banco compartilhado.
3. Demonstrar login.
4. Demonstrar Dashboard por perfil.
5. Demonstrar cadastros principais no Desktop.
6. Demonstrar matricula.
7. Demonstrar notas e frequencia.
8. Demonstrar pagamento.
9. Mostrar documentos de homologacao e bugs.
10. Demonstrar acesso Web por perfil, se ja validado.
11. Mostrar documentacao e status do projeto.
12. Encerrar com proximos passos.
