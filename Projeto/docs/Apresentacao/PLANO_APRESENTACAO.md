# Plano de Apresentacao

## Objetivo

Apresentar o Flow Academy como sistema de gestao escolar com modulo Desktop administrativo, modulo Web por perfil e banco MySQL compartilhado.

## Partes da apresentacao

| Parte | Responsavel |
|---|---|
| Introducao do projeto | A definir pelo grupo |
| Arquitetura geral | A definir pelo grupo |
| Banco de dados | A definir pelo grupo |
| Modulo Desktop | A definir pelo grupo |
| Modulo Web | A definir pelo grupo |
| Regras de negocio | A definir pelo grupo |
| Encerramento | A definir pelo grupo |

## Telas a demonstrar

### Desktop

- Login
- Dashboard `FrmPrincipal`
- Usuarios
- Alunos
- Professores
- Cursos
- Disciplinas
- Turmas
- Matriculas
- Notas
- Frequencias
- Pagamentos

### Web

- Landing Page
- Login
- Dashboard de aluno
- Dashboard de professor
- Dashboard de coordenacao
- Dashboard administrativo
- Area de pagamentos, se validada

## Fluxo sugerido

1. Explicar o problema que o sistema resolve.
2. Mostrar arquitetura Desktop, PHP e banco compartilhado.
3. Demonstrar login.
4. Demonstrar cadastros principais no Desktop.
5. Demonstrar matricula.
6. Demonstrar notas e frequencia.
7. Demonstrar pagamento.
8. Demonstrar acesso Web por perfil.
9. Mostrar documentacao e status do projeto.
10. Encerrar com proximos passos.

## Pendencias

- Definir integrantes responsaveis.
- Definir banco limpo para demonstracao.
- Ensaiar fluxo completo.
- Garantir que o dashboard Desktop esteja finalizado antes da apresentacao.
