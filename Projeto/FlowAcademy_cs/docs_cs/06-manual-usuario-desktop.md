# 06 - Manual do Usuario Desktop

## Abrir sistema

1. Executar o projeto `FlowAcademy`.
2. A tela `FormLogin` sera aberta.
3. Informar e-mail e senha.
4. Clicar em `Entrar`.

## Primeiro acesso

Se o usuario estiver com `ultimo_login` vazio, o sistema abre a tela de primeiro acesso.

Nesta tela:

1. Digitar nova senha.
2. Confirmar nova senha.
3. Salvar.

Depois disso, o sistema abre o dashboard principal.

## Dashboard

O dashboard mostra:

- Usuario logado.
- Perfil.
- Data e hora.
- Menus liberados.
- Atalhos de funcionalidades.

Os menus mudam conforme o perfil.

## Perfil aluno

Menus:

- Boletim / Notas.
- Frequencia.

Uso:

- Consultar notas.
- Consultar frequencia.

## Perfil professor

Menus:

- Notas.
- Frequencia.

Uso:

- Lancar notas.
- Registrar frequencia.
- Ver apenas turmas vinculadas ao professor.

## Perfil coordenacao

Menus:

- Alunos.
- Cursos.
- Disciplinas.
- Turmas.
- Matriculas.

Uso:

- Gerenciar estrutura academica.
- Acompanhar alunos e turmas.

## Perfil administrativo

Menus:

- Alunos.
- Matriculas.
- Pagamentos.

Uso:

- Gerenciar rotinas operacionais.
- Matricular alunos.
- Controlar pagamentos.

## Perfil admin

Menus principais:

- Alunos.
- Professores.
- Funcionarios.
- Cursos.
- Disciplinas.
- Turmas.
- Matriculas.
- Notas.
- Frequencia.
- Pagamentos.

Uso:

- Acesso amplo aos cadastros principais.
- Apoio a administracao geral do sistema.

## Padrao de uso dos formularios

Na maioria das telas:

- `Salvar`: cadastra ou atualiza registro.
- `Editar`: carrega o item selecionado no formulario.
- `Excluir`: remove o item selecionado.
- `Cancelar`: limpa campos.
- `Pesquisar`: filtra a listagem.
- Duplo clique no grid pode carregar o registro para edicao.

## Sair do sistema

1. Clicar no botao `Sair`.
2. Confirmar a saida.
3. A sessao e limpa e o sistema volta ao fluxo de login.
